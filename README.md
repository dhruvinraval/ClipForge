# ClipForge
ClipForge is a local video clipper. Give it a long video (file, link or path) and it transcribes the speech with Whisper, scores moments for hook, emotion, pace and energy, picks the best ones, reframes them to 9:16, 4:5, 1:1 or 16:9, adds animated captions, a title hook and a progress bar, then exports ready-to-post MP4s.
